ES Thesis Playbook Daily 15-Minute Memory Refresh - Version 1

THE PURPOSE Read this once each trading day until the six stories become automatic. Do not memorize pattern names in isolation. Refresh the behavioral sequence, what qualifies the thesis, what invalidates it, where the trade should go, and when you are forbidden to add.

Time Review

1 min Master flow: Context -> Control -> Location -> Attempt -> Response -> Destination -> Equation -> Act

8 min A-tier: Strong Trend, Channel PB, BO-Acceptance-BOPB, Range-Extreme Failed BO (about 2 min each)

2 min B-tier: Failed Reversal / Failure-of-Failure Resumption

2 min Observe-only: Mature-Trend Transition / MTR

2 min Final recall: Say the six thesis names from memory and state one disqualifier for each

NON-NEGOTIABLE RULES 1. Regime sets the default expectation; price action must earn an exception. 2. Damage is not automatically a flip. 3. Breakout is a claim; follow-through determines acceptance. 4. Structure sets the stop; risk budget sets size. 5. Nearest reasonable destination first. 6. Every add must independently earn its existence. 7. If the thesis or equation is unclear, WAIT or DO NOTHING.

THE SIX STORIES A-tier: 1) Strong-Trend Continuation; 2) Channel Pullback / Resumption; 3) Breakout -> Acceptance -> BOPB; 4) Range-Extreme Failed Breakout. B-tier: 5) Failed Reversal / Failure-of-Failure Resumption. Observe-only initially: 6) Mature-Trend Transition / MTR.

Goal: recognize the market story first; use patterns only as evidence inside that story.
